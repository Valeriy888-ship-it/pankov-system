# ПАНКОВ SYSTEM

Лендинг системы роста и бизнес-наставничества для косметологов: https://valeriy888-ship-it.github.io/pankov-system/

## Структура проекта
- `index.html` — основная страница с блоками проблем, инженерного метода, результатов, статей и формой записи на диагностический разбор.
- `privacy.html` — политика конфиденциальности и реквизиты оператора.
- `site.webmanifest`, `robots.txt`, `sitemap.xml` — конфигурация PWA и индексации.
- `images/` — портрет `valery-pankov.jpg`, логотип `logo.png` и комплект иконок.
